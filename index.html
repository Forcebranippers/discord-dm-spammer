Frequently asked questions

Everything you might want to know before downloading.

What exactly does Discord DM Spammer do?+

It's a Windows desktop tool that sends direct messages to a list of Discord recipients in bulk. It manages multiple account tokens, rotates them to spread requests, supports proxies, and queues messages behind an adaptive rate limiter so large batches finish reliably.

Does it require my Discord password?+

No. The tool works with account tokens that you supply yourself in the local configuration file. Credentials are stored locally on your machine — nothing is uploaded to any external server, and the source code is open for inspection.

How does the rate-limit bypass work?+

Rather than hammering the API, the engine reads rate-limit responses per account and per route, then schedules the next send for the exact reset window. Combined with token rotation and optional proxies, it keeps throughput steady without tripping hard blocks.

Is it free, and does it get updates?+

Yes — the project is free and open source. Every release ships as a portable Windows build with a changelog, and the repository accepts issues and pull requests for new features like template variables and proxy pool formats.
